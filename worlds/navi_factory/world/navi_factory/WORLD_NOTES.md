# navi_factory 월드 작업 노트

`navi_factory.sdf` 지금까지 어떤 모델들을 배치했는지 이유에 대해 간단히 작성

## 기본 구조

- 베이스 창고: `warehouse_mohamedazimal27_2x` (2배 스케일). 벽/바닥 텍스처는 원본 대신 갈아끼움 — 벽은 예전 `WallB_01` 삭제됐던 거 git 히스토리에서 복구해서 블러 먹인 오프화이트 플라스터로, 바닥은 원래 있던 아스팔트 텍스처를 밝게 보정해서 씀. 

4개 구역(NW/NE/SW/SE) = 창고를 사분면으로 나눠서 각자 세트로 꾸밈. 각 구역마다 라바콘 색깔 하나씩 배정: **NW=빨강, NE=주황, SW=노랑, SE=파랑**.

## 구역(NW/NE/SW/SE) 공통 구성 — 4개 세트 다 똑같은 패턴

각 구역마다 이런 것들이 들어감:

- **선반 4개(ShelfD_01 x2 + ShelfE_01 x2, 2x2 배치)** — aws_robomaker 창고 에셋, 실제로는 노란 프레임(그래서 "노랑철제"). 구역 중심 기준 x±3.3m, y±2.7m로 배치. 원래 좀 더 촘촘했는데 나중에 라바콘 도는 차 동선 확보하려고 바깥으로 밀었음.
- **클러터 5개(ClutteringA/C/D 중 랜덤)** — 그냥 잡동사니 박스들, 선반 바깥쪽 빈 공간에 랜덤 배치+최소 간격 보장해서 안 겹치게 뿌림.
- **라바콘 1개** — 구역 정중앙에, 원본이 8cm짜리라 너무 작아서 10배 키움. 색은 구역별로 다름(위 참고).
- **소화기 1개** — 콘 기준 북쪽 1.8m 지점. 원본 Fuel 모델에 딸려온 관계없는 서브모델(Artifact Proximity Detector)은 제거하고 넣음. 스케일은 10배→3.33배로 최종 조정(너무 커서 줄임).
- **반자동 지게차(PalletJack) 1개** — NW, SE 두 구역에만 있음(4개 다 랜덤으로 뽑았는데 이 둘만 걸림). 1.5배 스케일.
- **타이어 1개** — 원래 3개 구역(SW/NW/NE)에 넣으려 했는데 10배로 키우니까 지름 4.3m짜리 괴물이 돼서 구역 안에 도저히 안 들어감. 그래서 전부 구역 밖 빈 공간(클러터 링이랑 벽쪽 shelf_big 사이 갭)으로 재배치함.

## 벽쪽 대형 오브젝트

- **shelf_big(대형 3단 철제 선반) 12개** — 동서남북 벽 쪽에 3개씩. 실측 18m라 5m 줄여서(스케일 ~0.7배) 배치, 개체마다 스케일/각도 살짝씩 다르게 줘서 기계적으로 안 보이게 함.
- **Mecanum lift(소형 리프트) 3개** — 벽쪽 빈 공간에. 원래 바퀴 조인트 달린 진짜 로봇 모델이라 물리엔진이 계속 굴리려고 해서 `static=true`로 고정박아버림.

## NE 구역(주황) 현재 트랙은 여기만 넣었음

- 콘(11,13) 중심으로 작은 원형 점선 루프(반지름 1.3m, 흰색 아니고 콘 색이랑 맞춘 주황).
- 진입로: 자동차 출발점(0,36, AMR 대기 지점)에서 **정중앙 그대로 쭉 직진** → **좌회전 딱 한 번** → 선반 사이 통로 뚫고 콘까지. 대각선 이동 없음, 꺾는 것도 한 번뿐.
- 점선 두께는 바닥에서 12cm 튀어나오게 해서 눈에 확실히 보이게 함(처음엔 너무 얇아서 바닥에 묻혀 안 보였음).
- 나머지 3개 구역(NW/SW/SE)은 아직 트랙 안 만듦. 나중에 이 패턴 그대로 복붙할 예정.

## 0725 오늘 작업분 — OGV(자동차) 손봄

- `amr_queue_1`(OGV 차량 모델)에 **카메라 센서 + 라이더(gpu_lidar) 센서** 직접 추가함. 외형 모델(RGBD Camera, Lidar 3d v1 같은 Fuel 모델) 안 붙이고, `<sensor>` 태그만 링크에 바로 박아넣는 방식으로 함 — 센서는 메시 없이도 기능만 독립적으로 동작하니까.
- 차량스케일 키우고 맵 전체적으로 차량동선 생각했을때 널널하게 넓혔음
