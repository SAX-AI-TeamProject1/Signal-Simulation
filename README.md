# Signal-Simulation

카메라가 감지한 신호수(신호를 주는 작업자)의 수신호를 인식해 물류 이동 로봇을 정지/좌회전/우회전 시키는 프로젝트의 Gazebo 시뮬레이션 + 로봇 담당 리포지토리입니다. 신호수를 못 보고 발생하는 사고를 줄이고, 사람이 수신호로 로봇을 직접 명령할 수 있게 하는 것이 목적입니다.

카메라 이미지 처리·AI 추론(신호수 감지, 동작 인식)은 별도 리포지토리에서 개발되며, 이 리포지토리는 그 결과(명령)를 ROS 2로 받아 Gazebo 상의 로봇을 제어합니다.

## 스택

ROS 2 Jazzy + Gazebo Harmonic (`gz sim`), Python 3.12
